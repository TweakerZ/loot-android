# 0.1.3

Loot no longer shows an icon in the app drawer and installs under a new package
ID.

**What's new**

- App name is now Loot.
- New package ID `com.skyrimandroid.loot`. It installs beside the old app, which
  has to be removed by hand.
- No launcher icon. Skyrim Mod Loader starts the app by component name; until
  that entry ships, it has to be started directly.
- Port folder and file paths start empty after the package change.

**Install**

Download LootAndroid-0.1.3.apk and install it. Android 7.0 (API 24) or newer.

**Notes**

- All-files access has to be granted again for the new package.
- The first sort needs a connection to fetch the masterlist.

Yes, AI was used in building this.
