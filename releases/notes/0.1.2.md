# 0.1.2

Compose interface, a new launcher icon and the Skyrim Mod Loader name.

**What's new**

- Screen rebuilt on Jetpack Compose: status chips, load order overview, sort
  report and settings sheet.
- New adaptive launcher icon, with a monochrome layer for themed icons.
- Subtitle and Plugins.txt hint now name Skyrim Mod Loader.

**Install**

Download LootAndroid-0.1.2.apk and install it over the existing app. Android 7.0
(API 24) or newer.

**Notes**

- All-files access is required so libloot can read and write game files.
- The first sort needs a connection to fetch the masterlist.

Yes, AI was used in building this.
