# 0.1.4

The sort log and manual path prompt now use the app's own dialogs.

**What's new**

- Sort log opens in an in-app dialog instead of a system alert, with selectable
  text and the same styling as the rest of the app.
- Manual path entry, shown when a folder picker does not expose a real path, uses
  the in-app dialog too.

**Install**

Download `LootAndroid-0.1.4-launcher.apk` for a normal app drawer icon, or
`LootAndroid-0.1.4-iconless.apk` when Skyrim Mod Loader starts the app. Both are
0.1.4 with the same package and signature, so installing one replaces the other.
Android 7.0 (API 24) or newer.

**Notes**

- All-files access is required so libloot can read and write game files.
- The first sort needs a connection to fetch the masterlist.
- The iconless build stays startable by component:
  `com.skyrimandroid.loot/com.lootandroid.MainActivity`.

Yes, AI was used in building this.
